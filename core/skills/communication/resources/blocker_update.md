# Blocker / Incident Update Template

> First line states the problem. Recovery plan before apology.

```text
*BLOCKED: [what is broken/stuck, one line]*

Impact: [who/what is affected, since when]
Cause: [known cause | "investigating, suspect X"]
Tried: [what has already been attempted]
Need: [person] to [specific action] by [time]
Workaround: [interim mitigation | "none"]

Will update by [time] or when status changes.
```
