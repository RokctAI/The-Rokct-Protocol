# Frappe Composer Skill

This skill automates the compilation/pouring of DocTypes, Python controllers, and configuration hooks from reusable sibling SDK repositories into target backend app shells.

## Usage
Run the script `scripts/compose.py` inside the root of any Frappe App Shell containing a valid `composer.json` configuration file.
